Connect this page to GitHub once

Your changes are already kept on this device. To save them to GitHub too (so Kseniia sees them), paste a GitHub key here. You only do this once on each device.
  1. Open New fine-grained token on GitHub.
  2. Name it "Kseniia page". Expiration: the longest you like.
  3. Repository access: Only select repositories → englishwitholya.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate the token, copy it and paste it below.

The key stays only in this browser. It is never put on the website.
